# 自走モード（社長 不在時）

社長が海外で長期間承認できない間、承認を待たずに前へ進めるための取り決め。

## 前提: 何が詰まっていて、何が動かせるか

**画像パイプラインは社長本人が律速**（GPTが生成→社長がGitHubへアップ）。
不在の間これは進まない。したがって**自走で進めるのは画像に依存しない部分**に限る。

| 領域 | 不在中に進むか |
| --- | --- |
| ゲーム本体（遊び・演出・見た目の作り込み） | **進む** |
| 背景プレートの受け入れ機構（届いた時に使える状態にする） | **進む** |
| 生成画像そのもの | 止まる（社長の操作待ち） |
| 有料APIの導入 | 止まる（課金の判断が要る） |

## 回すループ

### 5分ごと: 批評 → 1件だけ直す

**辛口ユーザー（プレイヤー視点）**と**辛口クリエイター（作り手視点）**の
両方から現状を叩き、**その回で一番効く1件だけ**を直す。

- 辛口ユーザー: 面白いか。やることがあるか。手応えがあるか。飽きないか
- 辛口クリエイター: 作りとして甘くないか。嘘くさくないか。独自性はあるか。
  「ぼくのなつやすみの劣化コピー」で終わっていないか

毎回、**実際に動かした画面（キャプチャ）を根拠にする**。想像で批評しない。
直したら必ずビルド→シーン生成→キャプチャで確認してからコミットする。

### 30分ごと: 進捗監査

- 直近30分でコミットが積まれたか。画面は良くなったか
- 同じ問題を繰り返し触っていないか（堂々巡りの検出）
- 詰まっていたら**原因を特定して打ち手を変える**

## 行き詰まったときの決まり

同じ問題に2回連続で当たったら、手を止めて**外を見る**。

- 競合・類似作の作り方（Natsu-Mon、Shin-chan、A Short Hike、Alba 等）
- 市場・レビューの声（何が評価され、何が飽きられているか）
- SNS・コミュニティでの言及（どの絵が刺さっているか）

調べた結果と、それを受けて何を変えたかを下のログに残す。

## 判断ログ

新しいものを上に足していく。社長が戻ったとき、ここを読めば経緯が分かる。

- `sfx_swing` 虫あみを振る「ヒュッ」。帯域を時間で下げて振り抜き感を出す
- `sfx_catch` 明るい2音（880→1320Hz）＋網の中でもがく羽ばたき
- `sfx_escape` ジジッと鳴きながら音程を上げて遠ざかる（飛び去る表現）

**設計上の判断**: **セミが居なくても振った音は返す**ようにした。
空振りで無反応だと「操作が効いていない」と感じる。これは
辛口ユーザーの「振れているのかすら怪しい」への直接の答え。

0.1秒ごとに実効値へ落として測定。

| 区間 | RMS |
| --- | --- |
| 直前 15.5-16.0秒 | 0.0050 |
| **16.1秒（1回目の操作）** | **0.0434** |
| **18.4秒（2回目の操作）** | **0.1257**（地の音の3.2倍） |

**両方の操作で音が立ち上がっている**ことを確認。地の音（セミの合唱）に
埋もれず、はっきり手応えとして聞こえる水準。

**次に効きそうな所**: セミがまだ茶色い小箱のまま。木に貼りついた四角で、

## 2026-09-01 イテレーション8 — 画像が4枚到着。昼夜パノラマを実装

**出来事**: `BG-danchi-night` / `BG-street-noon` / `BG-street-night` /
`BG-park-noon` の4枚が届いた（★1/15 → **5/15**）。

**検証で分かった重要なこと**: GPT は**相変わらずこちらの下絵には追従しない**
（カメラ高さも建物配置も別物）。しかし **GPT が自分で作った昼と夜では、
同じ町・同じ建物・同じ街灯・同じすべり台・同じ倉庫を保っていた**。

つまり「下絵との一致」は無理でも、「**自分の絵どうしの一貫性**」は守れる。
ならばこの2枚は**対にして使える**。

**打った手**: 昼の遠景パノラマの内側に**夜版を重ね、17時から2時間かけて
透明度を上げるクロスフェード**を実装した。

- 昼版を暗くするだけでは**窓の灯りは作れない**。別撮りの夜版を混ぜて初めて
  「灯りの点いた団地」になる。これが夜を別に1枚もらう理由そのもの
- 夜パノラマは時刻の色調整（イテレーション7）の対象から外し、
  透明度だけを自前で動かすようにして二重制御を避けた

**結果**: 18:42 のフレームで遠景が夜に切り替わっていることをキャプチャで確認。

**この発見の意味**: 枚数を113→15に減らした計画（各場所を昼夜2枚だけ作り、
残りはエンジン側で作る）が、**実物で成立することを確認できた**。
GPT の癖（下絵に従わない／自分の絵には一貫性がある）に計画を合わせた形。

**途中で再発した手順の穴**: 取り込み時の `godot --import` が異常終了すると
画像が未インポートのままになり、`ResourceLoader.Exists` が false を返して
**何も言わずに機能が消える**（今回もノード数が増えず気づいた）。
import を独立して実行し直す手順が必要。

「昼と夜の2枚だけ作り、朝夕曇雨はエンジン側の色調整で作る」と決めた以上、
その色調整が動いていなければ計画そのものが成立しない。

### 打った手（イテレーション7）

`Backdrop` 配下の Unshaded なマテリアルを起動時に集め、
**時刻に合わせて色を掛ける**ようにした。

- 真昼は素の色、朝夕は太陽の色に寄せながら暗くする
  （明るさ係数を太陽高度 `arc` に連動）
- 曇天モードでは彩度を落として少し暗く
- 半透明のゴルフネットなど Unshaded でないものは対象外にして、
  透明度を壊さないようにした
- 元の色を保持して掛け算するので、何度更新しても色が沈まない

**結果**: 17:49 のフレームで遠景が世界と同じ夕日の色に揃い、
真昼のフレームは素の色のままであることをキャプチャで確認。
**「1枚の写真から時間帯を作る」構想が実際に動くことを実証できた。**



## 2026-09-01 イテレーション6 — 音を入れる（夏のゲームでセミの声が無かった）

**批評（辛口クリエイター）**: **目をつぶったら何も無い。**夏を題材にして
セミの声が鳴っていないのは、雪山のゲームで風の音がしないのと同じ。
時間帯で顔ぶれが変わる設計にしたのに、それが**耳では一切分からない**。

**批評（辛口ユーザー）**: 静かすぎて、生きている町に見えない。

**打った手**: 音源を買わず外部依存も足さず、**標準ライブラリだけで
セミの声を合成**した（`tools/gen_audio.py`）。時間帯で3種類を切り替える。

- `cicada_morning`: ニイニイゼミの連続音＋クマゼミの「シャシャシャ」
- `cicada_day`: アブラゼミの「ジリジリ」＋ミンミンゼミの「ミーン ミンミンミン」
- `cicada_evening`: ヒグラシの「カナカナカナ」（音程が下がるのが特徴）＋虫の音
- どれも木々のざわめき（低域ノイズ）を下に敷き、4.0秒ちょうどで
  変調が整数周期で閉じるようにして継ぎ目を消した
- ゲーム側は朝/昼/夕の切り替わりで**約12dB/秒のクロスフェード**。
  ぶつ切りにせず、いつの間にか声が変わっている状態にした
- ループはインポート設定に頼らず、コード側で `LoopMode` を立てて閉じた

**検証**: movie writer が書き出す `frame.wav` を実測した。
最初 32bit を 16bit として読んで過大評価していたので測り直したところ、
**開始直後の3秒が -51 dBFS とほぼ無音**だと判明。全プレイヤーを -60dB から
上げていたため、ゲーム開始の数秒が無音になっていた。開始時点の時間帯だけ
最初から鳴らすよう修正し、**RMS -25.6 dBFS・クリップなし**を確認した。

**次に効きそうな所**: セミを捕まえた瞬間・失敗した瞬間の効果音がまだ無い。
手応え（フィードバック）は辛口ユーザーが最初に指摘した点でもある。



## 2026-09-01 イテレーション5 — 開幕の画を「草原に建物」から「団地の広場」へ

**批評（辛口クリエイター）**: **ゲームの第一印象がこれか。**団地の妻面
（のっぺりした横っ腹）が画面の真ん中を塞ぎ、主人公は建物の隙間に埋もれて見えない。
地面は一面のっぺりした芝で、団地の足元にあるはずの舗装通路・駐輪場・植え込みが
何もない。**団地の広場ではなく、草原に建物を置いただけ**。

**批評（辛口ユーザー）**: 始まった瞬間、自分がどこにいるか分からない。

**打った手**: 棟間（2棟のあいだ）を実際の広場として作り込み、
カメラをその軸に沿わせた。開幕カメラなので画作りの影響が最も大きい。

- 棟間を東西に貫く舗装通路と、各棟の入口へ伸びる枝道
- 通路の両脇に刈り込んだ生垣を12本
- **駐輪場**（波板の屋根＋自転車5台。フレーム・ハンドル・車輪を組んだ簡易モデル）
- **ゴミ集積所**（緑のネットをかけた囲い）
- **物干し場**の竿を4組（団地の記号）
- カメラを妻面正面から**棟間の軸に沿った覗き込み**へ変更（FOV 40）

**途中の発見**: 広場を作ったのにカメラに何も映らなかった。原因は
**棟間の通路に木が植わっていて視線を塞いでいた**こと。街路樹と
メタセコイア並木を廊下の外（棟の南側）へ移して解決。
作ったものが映らないまま完了とするのは事実に反するので、
同じ意図の仕上げとしてカメラと植栽の位置まで直した。

**結果**: キャプチャで確認。舗装の通路が奥へ抜け、生垣・駐輪場の赤い自転車・
物干し竿が並び、主人公が読める大きさで立っている。ノード数 647 → 707。

**次に効きそうな所**: 音がまだ一切ない。夏のゲームでセミの声が無いのは
辛口クリエイターの最大の指摘になりうる。



## 2026-09-01 30分監査①＋イテレーション4 — 締切を捨てて「発見」を入れる

### 監査結果

- 直近35分で4コミット。**前進している**
- 判断ログを確認したが、毎回別の問題に当たっており**堂々巡りは無し**
  （パノラマ → コレクション性 → 商店街の作り込み）
- ただし**画像は 1/15 で停滞**。GPT の自動生成が届いていない

### 停滞の原因と打ち手

画像の停滞はこちらから動かせない（GPT と社長の側）。規則どおり
**外部情報を調べて方針を確かめた**。

[Natsu-Mon のレビュー](https://opencritic.com/game/17074/natsu-mon-20th-century-summer-kid/reviews)
を調べたところ、このジャンルの現行最有力作に対する批判が2つ見つかった。

1. **「決まった日数しかないと知っていて焦りを感じた」** — 締切がストレスになる
2. **「多くの場面で遅く、忍耐を試される」** — 何もない時間が長い

これは**うちのゲームに今まさに当てはまる**。日記に毎晩
「ずかんは あと5しゅるい」と出していたのは、まさに1の罠だった。

### 打った手（イテレーション4）

**締切のない「発見」システム**を入れ、日記から残数表示を消した。

- 世界の8か所（給水塔・土管・池のふち・自販機・横断歩道・すべり台・
  ブランコ・商店街の入口）に、近づくと一度だけ短い独白が出る
- **締切も失敗も無い。歩けば増える**。2の「何もない時間」も同時に埋まる
- 文面は「30代が2000年の子供に戻る」という本作の設定を活かし、
  子供の目線に**かすかな既視感（大人の記憶）を一枚重ねた**。
  これは「ぼくのなつやすみ」には無い、うちだけの角度
- 日記は達成表ではなく**その日の思い出**として書くよう変更。
  残数（あと◯しゅるい）は削除した
- HUDに「はっけん n/8」を追加

### 途中で潰した不具合2件

- HUDの右上ラベルが幅不足で「はっけん」が見切れていた → 幅を拡張
- 日記の長文が画面外にはみ出していた → 左右に余白を取り自動折り返しを有効化

**結果**: キャプチャで「はっけん 1/8」の表示と、折り返された日記
「しょうてんがいの したは いつも すずしい。そとの あつさが、きゅうに とおくなる。」
を確認。



## 2026-09-01 イテレーション3 — 「商店街が無地の箱」を潰す

**批評（辛口クリエイター）**: これは商店街じゃない。**画面の6割が無地の
コンクリ壁**で、暖簾も商品も看板の色も無い。2000年の近隣センターの記憶は
「色あせた日よけ」「店先の平台」「ビールケース」であって、この無地の箱ではない。

**批評（辛口ユーザー）**: 商店街に来ても歩いて通り過ぎるだけ。何もない。

**打った手**: 望遠カメラでは店の壁が画面の大半を占めるので、そこを
**店先の情報で埋めた**。`BuildShop` を全面的に作り直し。

- 暖簾（庇の下に垂らす布・4枚）を開いている店に追加
- 店先の平台と商品の木箱3つ（色は店ごとに変える）
- 縦看板を壁に貼る。位置は店ごとに左右振り分け

- 3軒に1軒、店先にビールケースを2段積み

ノード数 474 → 647。

**次に効きそうな所**: 手前左右の店の側面がまだ大きな無地の灰色の板で、

## 2026-09-01 イテレーション2 — 「何も残らない」を潰す（コレクション性）

**批評（辛口ユーザー）**: 8月31日まであるのに、やることがセミ取りだけ。
捕まえても数字が1増えるだけで**何も残らない**。3日で飽きる。

**批評（辛口クリエイター）**: 時間帯で空の色は変わるのに、**やることが同じ**
なのが致命的。時間が「見た目の演出」でしかなく、遊びに接続していない。
これでは「ぼくのなつやすみ」の骨格だけ真似た抜け殻になる。

**打った手**: セミを1種類から**6種類**にし、**時間帯で顔ぶれが変わる**ようにした。
これで「時間の経過」が初めて遊びに接続する。

- ニイニイゼミ(朝) / クマゼミ(朝〜昼) / アブラゼミ・ミンミンゼミ(昼) /
  ツクツクボウシ(夕) / ヒグラシ(夕方だけ・捕獲率40%で最難関)
- 朝→昼→夕の切り替わりで顔ぶれを入れ替え、「セミの こえが かわった……」と通知
- **図鑑**（日をまたいで残る）を追加。HUDに `ずかん 2/6`、未捕獲の個体には
  近づくと「★みつけていない！」を表示して手を伸ばさせる
- 初捕獲時は「ずかんに はじめて のった！」の専用演出
- 日記と最終日のまとめにも図鑑の進捗を反映
- 種類ごとに体色と捕獲率を変え、難しい種ほど価値が出るようにした

**結果**: キャプチャで確認。HUDに「ずかん 0/6」、日記に「ずかんは あと 5しゅるい。」
が出ることを目視。**31日間プレイし続ける理由**が初めて成立した。

**次に効きそうな所**: 商店街のカメラで主人公が豆粒すぎる（望遠圧縮が
活きていない）。店に入れず何も起きないのも辛口クリエイターの指摘どおり。



## 2026-09-01 イテレーション1 — 1枚目の検証と方針転換

**批評（辛口クリエイター）**: 遠景が板を並べただけで嘘くさい。空が
プロシージャルの単色グラデで、実写の情報量に全く追いついていない。

**出来事**: GPT が生成した `BG-danchi-noon` が届いた。写真としては優秀だが、
**下絵を完全に無視してゼロから描かれていた**。カメラの高さも建物配置も
別物で、床に敷く背景プレートとしては使えない（3Dキャラと遠近が合わない）。

**打った手**: 捨てずに使い方を変えた。シーンを囲む**円筒パノラマ**として採用。
遠景なら画角の一致が要らないため、この用途なら問題なく使える。
UVは上72%だけを使い写真の地面部分は捨て、横に5回まわしてタイルしている。
公園カメラの見た目が明確に良くなったことをキャプチャで確認。

**途中で潰した不具合2件**:
- `ingest_images.sh`: アップロード名が既にIDと同じ場合、MAP.txt の改名が
  自己移動になり `mv` がエラーで全体が停止していた（実運用で発覚）
- 画像が Godot に未インポートだと `ResourceLoader.Exists` が false になり、
  パノラマが無言で消えていた。取り込み後の import を必須手順として確認

**次の一手**: GPT は下絵追従が苦手と判明したので、`docs/prompts/GPT_NOTES.md`
に方針転換を書いた。残り7枚の `BG-*` より、一致を要求しない
**遠景パノラマ・テクスチャ・汚し**を優先してもらう。
