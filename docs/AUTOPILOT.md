# 自走モード（社長 不在時）

社長が海外で長期間承認できない間、承認を待たずに前へ進めるための取り決め。

## 前提: 何が詰まっていて、何が動かせるか

**画像パイプラインは社長本人が律速**（GPTが生成→社長がGitHubへアップ）。
不在の間これは進まない。したがって**自走で進めるのは画像に依存しない部分**に限る。

| 領域 | 不在中に進むか |
| --- | --- |
| ゲーム本体（遊び・演出・見た目の作り込み） | **進む** |
| 背景プレートの受け入れ機構（届いた時に使える状態にする） | **進む** |
| 生成画像そのもの | 止まる（社長の操作待ち） |
| 有料APIの導入 | 止まる（課金の判断が要る） |

## 回すループ

### 5分ごと: 批評 → 1件だけ直す

**辛口ユーザー（プレイヤー視点）**と**辛口クリエイター（作り手視点）**の
両方から現状を叩き、**その回で一番効く1件だけ**を直す。

- 辛口ユーザー: 面白いか。やることがあるか。手応えがあるか。飽きないか
- 辛口クリエイター: 作りとして甘くないか。嘘くさくないか。独自性はあるか。
  「ぼくのなつやすみの劣化コピー」で終わっていないか

毎回、**実際に動かした画面（キャプチャ）を根拠にする**。想像で批評しない。
直したら必ずビルド→シーン生成→キャプチャで確認してからコミットする。

### 30分ごと: 進捗監査

- 直近30分でコミットが積まれたか。画面は良くなったか
- 同じ問題を繰り返し触っていないか（堂々巡りの検出）
- 詰まっていたら**原因を特定して打ち手を変える**

## 行き詰まったときの決まり

同じ問題に2回連続で当たったら、手を止めて**外を見る**。

- 競合・類似作の作り方（Natsu-Mon、Shin-chan、A Short Hike、Alba 等）
- 市場・レビューの声（何が評価され、何が飽きられているか）
- SNS・コミュニティでの言及（どの絵が刺さっているか）

調べた結果と、それを受けて何を変えたかを下のログに残す。

## 判断ログ

新しいものを上に足していく。社長が戻ったとき、ここを読めば経緯が分かる。
