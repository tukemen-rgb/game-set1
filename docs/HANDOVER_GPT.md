# GPT への引き継ぎパック — 「ニュータウンの なつやすみ」

社長の判断で、**質感・リアリティに強い GPT にもこのゲームを作らせる**ことになった。
この1本に、企画・仕様・いま出来ている物・写真との差・欲しい素材の仕様・動かし方を
まとめる。ChatGPT に貼る指示文は最後の「§9」にある（そこだけ貼れば始められる）。

リポジトリ: `tukemen-rgb/game-set1`（ブランチ `claude/game-godot-setup-98dhue`）。
経緯の全記録は `docs/AUTOPILOT.md`（新しい順・84 回分）、状態は `README.md`。

## 1. 企画の核（これだけは変えない）

- **30 代のサラリーマンが、2000 年 8 月の「ぼく」（10 さい）に戻って、ひと夏を過ごす。**
  舞台は千里ニュータウン風の**団地・商店街（近隣センター）・公園（丸い池）・空き地**。
- 「ぼくのなつやすみ」系。**締切も失敗も無い**。歩けば増える発見、時間帯で変わる虫、
  日ごとに育つあさがお、日記で一日を閉じる。
- 導入は「二〇二六年。会議、見積、終電。」→ 目が覚めるとセミの声。結末は 2026 年に
  戻って、その夏に集めた物を数える。最後の一行はプレイで変わる。
- **画像は GPT が作り、社長が GitHub に上げる**（これまでのやり方。`docs/AI_IMAGE_WORKFLOW.md`）。

## 2. 一日と一月の仕組み（数値はそのまま使ってよい）

| 仕組み | 決め方 |
| --- | --- |
| 期間 | 8/1(火)〜8/31。1 日は 8:00〜19:00。実時間で 1 日 ≒ 3.7 分（1 時間 = 20 秒） |
| 天気 | 日付から決定的に決まる。`h=(day*37+11)%100`、h<18 雨・h<40 くもり・それ以外 晴れ。雨は 8/8・17・19・27（8/16 の送り火の日は 17 日と入れ替えて晴れ） |
| 行事 | 8/7 ラジオ体操最終日 / 8/13 お盆（窓の灯りが増える）/ 8/16 送り火 / 8/24 夏まつり（提灯・屋台・18:30 から花火） |
| 十円 | 自販機の下。`(day*29+41)%100<20` の日（8/6・9・13・16・23・30） |
| セミ | 6 種。ニイニイ 8–11 時 / クマ 8–13 / アブラ・ミンミン 10–17 / ツクツクボウシ 15–19 / ヒグラシ 17–19。捕獲率 0.4〜0.75。走ると逃げる。歩いても 2.8m 以内は毎秒 12% で隣の木へ飛ぶ。外すと 6m 先の木へ飛ぶ |
| 雨の日 | セミは出ず、カタツムリ・アマガエルだけ |
| 甲虫 | 樹液のくぬぎに、8:00–9:30 と 17:00 以降だけ。雨の日は来ない |
| ザリガニ | 池のふちで「垂らす→待つ→『ツン、と ひいた！』で 1.1 秒以内に引く」 |
| あさがお | 双葉→本葉→つる→つぼみ(8/13〜)→花(8/16〜)。咲く数は日で変わり、咲かない朝もある |
| お金 | 毎朝 100 円、上限 900 円。駄菓子屋でラムネ 100 / あたりくじ 20 / アイス 50、祭りはかき氷 100 / りんご飴 150 / 金魚すくい 200 |
| 発見 | 8 か所。近づくと独白。8/16 以降に戻ると「その後」の独白 |
| 町の人 | 駄菓子屋のおばあさん（雨の前日は予報を当てる）、おじいさん、おばさん 2 人。台詞は日付の範囲付き |

## 3. いま出来ている物（証拠つき）

## 4. 技術構成

- **Godot 4.4 mono（C#）**、レンダラは `gl_compatibility`（社長の環境と検査環境が
  ソフトウェア描画のため。映り込み・SSR は出ない）
- 場面は手で作らず `scenes/BuildSummer.cs` がプリミティブ（Box/Cylinder/Sphere/Torus）で
  `scenes/summer_main.tscn` を**生成**する。遊びの全ロジックは `scripts/SummerMain.cs`
- 検査は `test/*.cs` を `--script` で走らせ、`--write-movie` で連番 PNG＋WAV を撮る。
  `tools/shoot_all.sh` / `tools/make_video.sh` / `tools/check_audio.py`
- 実写風の素材はすべて GPT 製（`assets/plates/BG-*.jpg` 遠景 8 枚、`assets/sky/SKY-*.jpg` 2 枚、
  `assets/textures/gen/TEX-*.jpg` 2 枚、キーアート）。プレート以外の材質はプロシージャル

## 5. 写真（`docs/reference/park_pond_gpt.png`）と今の差 — GPT に一番助けてほしい所

比較画像: `docs/reference/park_compare.png`（左が写真、右が現状）。

| 差 | いまの作り | 欲しい物 |
| --- | --- | --- |
| 芝の質感 | 合成の粗い芝（`gen/grass_coarse.png`） | **タイル可能な芝** 2048²、踏まれて土が透けた所を含む、真上から、影なし |
| 空 | 写真パノラマの大きな雲 1 つ | **小さな積雲が散る夏空**の横長パノラマ（6144×1536 程度、水平線の少し上から天頂まで） |
| 地平線 | 写真の建物が芝と硬い線で接する | **地平線の木立の帯**（横長・下が透過 PNG、8192×512 程度） |
| 池のふち | 洗い出しコンクリ写真を tint | **洗い出しコンクリートのタイル** 1024²（粒 3〜5mm が見える） |
| 団地の壁 | 実写コンクリ壁＋合成の雨だれ | **雨だれのあるコンクリート壁のタイル** 2048²（階の継ぎ目なし） |
| 針葉樹・広葉樹 | 円錐・球に葉テクスチャ | 葉の**タイル**（密・暗緑）と、できれば **GLB の木**（下記の規約） |

## 6. 素材の受け渡し規約（この通りなら即座に組み込める）

- **テクスチャ**: PNG か JPG、sRGB、正方形（1024/2048）、**タイル可能**、影・ハイライトを焼き込まない。
  名前は `TEX-<name>.jpg`、置き場 `assets/textures/gen/`
- **遠景・空**: JPG、横長パノラマ（左右が繋がる）。名前 `BG-<place>-<time>.jpg` / `SKY-<name>.jpg`
- **3D モデル**: **GLB**、単位はメートル、Y が上、原点は接地点、実寸（すべり台 高さ 2m、
  街灯 4.2m、団地 1 棟 16×13.5×5m）、マテリアルは埋め込み。名前 `MDL-<name>.glb`、置き場 `assets/models/`
- 参考画像は `docs/reference/`、生成プロンプトの控えは `docs/prompts/`
- **使わないこと**: 実在の曲・実在のロゴ・実在の人物。有料 API は社長の判断なしに使わない

## 7. GPT がゲームを「作る」ときの決まり

- 同じ企画（§1）と同じ数値（§2）で作る。**別の遊びを足すより、写真の質感に寄せる**のが今回の主眼
- 出力は Godot 4.4 で開ける物（.tscn/.gd か .cs、GLB、テクスチャ）か、
  それが無理なら**素材と、置き方の指示**（位置・大きさ・材質の数値）でよい。こちらで組み込む
- 判断は社長がする。迷う所は「案 A / 案 B」で出す
- 進捗は「何を作った／どこに置いた／どう確かめたか」の 3 行で

## 8. 動かし方（社長 or GPT が確認するとき）

```bash
export DOTNET_ROOT=/opt/dotnet PATH="$PATH:/opt/dotnet"
dotnet build                                                     # C# ビルド
godot --headless --path . --script res://scenes/BuildSummer.cs   # シーン生成
godot --path .                                                   # 遊ぶ
SHOT_DAY=4 SHOT_HOUR=12.0 xvfb-run -a godot --path . --write-movie screenshots/x/frame.png \
  --fixed-fps 10 --quit-after 24 --script res://test/CamShots.cs # 6 カメラの静止画
```

操作: 矢印で歩く、Shift で走る、スペースで決定（虫あみ／話す／買う／垂らす／乗る）、Z でずかん。
