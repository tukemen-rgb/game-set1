# BalconySummerTomatoPlanter650

Distinct summer balcony context asset, not a replacement or duplicate for the existing morning-glory owner. The design is an original dimensional approximation inspired by common modern Japanese rectangular balcony planters and home tomato cultivation; it is **not** a claim that a specific 2000-era product had these exact dimensions.

Physical construction: 650 x 260 x 220 mm tapered polypropylene planter, 3 mm nominal shell, contained potting soil, three bamboo stakes with visible nodes, jute cross ties and stem ties, two tomato vines, compound serrated leaflet shells, rachises, flowers, calyx/pedicels and green/turning/ripe fruit. The planter is slope-matched to the existing waterproof floor rather than visually floated.

Material model: all new materials are dielectric (metallic 0). PP roughness 0.56-0.60; dry soil 0.96; bamboo 0.70; jute 0.92; living foliage/stem 0.68-0.74; tomato skin 0.40-0.50. No baked highlights or arbitrary dirt decals.

Actual external generation: MASTER/LOD0/LOD1/LOD2/LOD3 = 24,448 / 18,048 / 7,316 / 3,898 / 1,874 triangles. All generated component meshes are watertight, no degenerate faces were found, and GLB/OBJ triangle roundtrips matched for all levels.

Scene integration adds the asset to the latest `BalconyExteriorHeroSummerMorningGloryCanopy3600` without deleting or duplicating existing morning-glory geometry. Integrated triangle counts = 291,084 / 169,148 / 83,768 / 39,960 / 22,214. LOD0 conservative clearances: ~390.1 mm to facade plane, ~77.7 mm to main rail inner bound, ~328.7 mm from morning-glory canopy, ~957.5 mm from AC.

Material-colored diagnostic previews submit all 169,148 LOD0 triangles. They are **not Unity evidence**. Unity compile/import/render, native 4K crops and temporal LOD/shimmer remain unverified; Visual Fidelity stays unscored with zero points awarded. Binary GLB/OBJ and PNG outputs are delivered in the conversation package, not claimed committed to GitHub.
