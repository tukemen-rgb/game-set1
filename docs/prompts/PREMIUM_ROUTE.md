# ChatGPT の定額プランを使い切る進め方

## 大前提（誤解しやすい点）

**ChatGPT の月額プラン（Plus / Pro）と OpenAI API の課金は別勘定。**
定額プランに入っていても API のクレジットは付かないし、API を使えば
プラン料金とは別に従量課金が発生する。逆に言えば、

- **プラン内で画像を作る** → 追加費用ゼロ。ただし人が受け渡す
- **API で自動生成する** → 全自動。ただし別料金（113枚で約8ドル）

の二択になる。プランに入っているなら、前者を活かさない手はない。

## だから「パイプを太くする」より「枚数を減らす」

手作業の総量は **枚数 × 1枚あたりの手間**。手間の方は
GitHub のアップロード画面がある以上ゼロにはできない。
なら**枚数を削るのが正解**。113枚を精査したところ、
**15枚でゲームの見た目は変わる**と判断した。

| 分類 | 元 | フェーズ1 | 削った理由 |
| --- | --- | --- | --- |
| 背景 | 24 | **8** | 各場所「昼」と「夜」だけ作る。朝・夕・曇り・雨上がりは**エンジン側の色調整で作れる**（元々ゲーム内で空と光を時刻補間しているので、同じ係数をプレートにも掛ければよい）。夜だけは窓の灯りが要るので別撮り |
| 空 | 8 | **2** | 入道雲と夕焼けが効く。残りは色調整で足りる |
| テクスチャ | 24 | **2** | 外壁・アスファルト・舗装・砂利は Poly Haven の CC0 実写を導入済み。生成が要るのは芝と葉だけ |
| 汚し | 10 | **2** | 雨だれと木漏れ日が効きが大きい |
| キャラ | 15 | **0** | **画像を3Dモデルに変換する経路が無い**（Tripo3D の API が要る）。今作っても使えないので保留 |
| 小物 | 26 | **0** | 同上 |
| UI | 6 | **1** | タイトル用キーアートのみ |
| **合計** | **113** | **15** | |

15枚なら **4バッチ ≒ 5分**の手作業で終わる。API を使う理由がなくなる。

## 進め方

1. GPT に `STATUS.md` の★フェーズ1から順に作らせる（1回3〜4枚）
2. 社長は画像を保存して GitHub の `incoming/` にドラッグ＆ドロップ
3. GPT が `incoming/MAP.txt` に「ファイル名 = ID」を書いてコミット
4. 5分以内（Actions は毎時17分）に自動で振り分け・取り込み

APIキーは登録しなくてよい。鍵が無ければ自動生成はスキップされ、
取り込みだけが動く。**あとで気が変わったら鍵を足すだけで自動化に移行できる。**

## 定額プランの他の使いどころ

- **監督役**: GitHub 接続で `STATUS.md` を読み、進捗を報告させる（設定済み）
- **作り直しの指示**: `docs/prompts/REDO.txt` に ID を書かせる
- **プロンプトの改善案**: `docs/prompts/GPT_NOTES.md` に書かせる
- 画像の枚数制限に当たったら、翌日に持ち越せばよい（15枚なら数日で終わる）

## フェーズ2に進むとき

キャラ・小物の41枚は、3D化の経路（Tripo3D などの image-to-3D）を
用意してから着手する。それまでは**作っても置き場所しかない**。
背景の時間帯バリエーションも、色調整で足りなければ個別生成に戻せばよい。
