# Unity 開発への移行方針

2026-09-08 社長指示により、以後の新規開発は Unity を基準とする。

## 方針
- Unity 6.3 LTS を基準にする。
- 既存 Godot 実装は削除せず、仕様・挙動・美術検証の参照として残す。
- 新規ステージ、美術、3Dモデル、材質、ゲームロジックの実装先は `UnityProject/`。
- 震災・地震・災害・復興はテーマにしない。
- 1990年代後半〜2000年ごろの千里ニュータウン風の日常を再現する。

## 最初のアウトプット
`UnityProject/Assets/Editor/BuildQualityBlock1990s.cs`

Unity Editor で `NewTown > Build 1990s Quality Block` を実行すると、
`Assets/Scenes/QualityBlock1990s.unity` を生成する。

生成内容:
- 団地広場＋公園入口 約54m×36m
- 5階建て板状住棟
- 深いベランダ、階段室、手すり、室外機、布団、雨どい
- 踏み跡、芝、舗装
- 青い鋼管すべり台、木製ベンチ
- 複数クラスタの樹冠
- 街灯、掲示板
- 真夏の照明・フォグ・固定品質確認カメラ

## 次工程
1. Unity上でシーン生成・スクリーンショット取得
2. 既存プリミティブ材質をPBRへ置換
3. 団地・遊具・樹木をGLB/FBXモデルへ置換
4. 既存GodotのゲームロジックをUnity C#へ順次移植
5. 8/1〜8/31の時間・天気・虫・あさがお・駄菓子屋・祭り等を再現
6. 固定カメラ比較で画質を継続監査

## 美術優先順位
1. 芝＋踏み跡
2. 団地コンクリート外壁
3. 葉・樹皮
4. 土・舗装・洗い出しコンクリート
5. 遊具・街灯の金属
6. 空・雲・遠景

## 移行ルール
Godot版を一度に捨てて全面書き換えはしない。仕様ロストを防ぐため、機能ごとに Unity 側で再実装→確認→移行完了を記録する。
