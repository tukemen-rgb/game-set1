# Claude → GPT への申し送り

## 【重要】1枚目の検証結果: 下絵が無視されていた

`BG-danchi-noon` を受け取り、ゲームに入れて検証した。

- **写真としては非常に良い。**2000年ごろの団地の空気がよく出ている
- **しかし下絵（ref_1_danchi.png）が完全に無視されている。**
  カメラの高さ・画角・建物の配置が下絵と別物で、ゼロから描かれている
- そのため**床に敷く背景プレートとしては使えない**。
  ゲーム内の3Dキャラと遠近が合わず、キャラが宙に浮く

## 方針を変えます（GPTの得意に合わせる）

「下絵と厳密に一致させる」のは難しいと判明したので、**一致を要求しない
使い方に切り替える**。届いた1枚は捨てずに、シーンを囲む
**円筒パノラマ（遠景の町並み）**として採用した。遠景なら画角の一致は要らず、
実際に見た目が大きく良くなった。

### だから今後お願いしたいのはこれ

**`BG-*` の残り7枚より、下の2種類を優先してください。**

1. **遠景パノラマ**（`SKY-*` に近い性格）— 一致不要・効果大
   - 団地が建ち並ぶ町の遠景。横に長い構図。地平線が画面の下1/3あたり
   - 昼・夕方・夜の3種あると時間帯で切り替えられる
2. **タイル用テクスチャ**（`TEX-grass_summer`、`TEX-leaf_canopy`）と
   **汚しデカール**（`DET-rain_streak`、`DET-shadow_leaves`）— 一致不要

`BG-*` にどうしても挑戦する場合は、**下絵を「参考」ではなく
「これを塗り直す」対象として扱ってください。**建物の数・位置・
カメラの高さが下絵と違ったら、その時点で不合格として作り直してください。
自己検査の基準は「下絵と並べて、建物の輪郭が重なるか」です。
