# 1990s Quality Block — 団地広場＋公園入口

## 目的

広いマップを先に増やさず、固定カメラ1画面で「1990年代後半〜2000年ごろの千里ニュータウン風」に見える品質基準区画を作る。

**震災・地震・災害・復興はテーマ・背景設定・イベント・環境ストーリーテリングに使用しない。** 経年劣化は通常の雨風と生活使用だけで表現する。

## 現在の実装

`scenes/BuildQualityBlock.cs` を追加。既存 `summer_main.tscn` を壊さない独立ビルダーとして、次を実寸ベースで配置する。

- 5階建て板状住棟
- 深いベランダと奥まったサッシ
- 階段室の張り出し
- 手すり、室外機、布団、雨どい
- 団地広場の舗装
- 公園入口、踏み跡の土、夏芝
- 1990年代風の鋼管すべり台、ベンチ、街灯、掲示板
- 単一球ではなく複数クラスタで崩した樹冠
- 真夏の高い太陽、短い影、青空

## 生成方法

```bash
export DOTNET_ROOT=/opt/dotnet PATH="$PATH:/opt/dotnet"
dotnet build
godot --headless --path . --script res://scenes/BuildQualityBlock.cs
godot --path . res://scenes/quality_block_1990s.tscn
```

出力: `scenes/quality_block_1990s.tscn`

## 現段階の意味

これは最終美術ではなく**形状・実寸・光・配置の品質ゲート**。ここでカメラとシルエットを確定してから、以下の実写/PBR素材へ置き換える。

1. `TEX-grass-worn` — 夏芝＋踏み跡
2. `TEX-dirt-dry` — 乾いた土
3. `TEX-concrete-weathered` — 通常経年の団地外壁
4. `TEX-washed-concrete` — 洗い出しコンクリート
5. `TEX-leaf-broadleaf` — 広葉樹葉
6. `TEX-leaf-metasequoia` — メタセコイア系葉

次段階では Albedo / Normal / Roughness を分離し、GLBの樹木・遊具・街灯・団地モジュールへ順次置換する。

## 合格条件

- 一見してプリミティブCGに見えない方向へ改善している
- ベランダの奥行きと階段室の張り出しが画面で読める
- 団地に生活感があり、現代設備の過剰な混入がない
- 芝、舗装、土の面積比と実寸感が自然
- 樹冠が単一の球・円錐に見えない
- 真夏の光が強いが白飛びしない
- 震災・災害を連想させる破壊表現がない

## 次の実装

この区画の固定カメラ画像を取得して既存画面と比較し、PBR化の優先順位を決める。最優先は画面占有率が高い `芝 → 団地外壁 → 葉 → 舗装/土 → 遊具・街灯` の順。
