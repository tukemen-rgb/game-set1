# 自走モード（社長 不在時）

社長が海外で長期間承認できない間、承認を待たずに前へ進めるための取り決め。

## 前提: 何が詰まっていて、何が動かせるか

**画像パイプラインは社長本人が律速**（GPTが生成→社長がGitHubへアップ）。
不在の間これは進まない。したがって**自走で進めるのは画像に依存しない部分**に限る。

| 領域 | 不在中に進むか |
| --- | --- |
| ゲーム本体（遊び・演出・見た目の作り込み） | **進む** |
| 背景プレートの受け入れ機構（届いた時に使える状態にする） | **進む** |
| 生成画像そのもの | 止まる（社長の操作待ち） |
| 有料APIの導入 | 止まる（課金の判断が要る） |

## 回すループ

### 5分ごと: 批評 → 1件だけ直す

**辛口ユーザー（プレイヤー視点）**と**辛口クリエイター（作り手視点）**の
両方から現状を叩き、**その回で一番効く1件だけ**を直す。

- 辛口ユーザー: 面白いか。やることがあるか。手応えがあるか。飽きないか
- 辛口クリエイター: 作りとして甘くないか。嘘くさくないか。独自性はあるか。
  「ぼくのなつやすみの劣化コピー」で終わっていないか

毎回、**実際に動かした画面（キャプチャ）を根拠にする**。想像で批評しない。
直したら必ずビルド→シーン生成→キャプチャで確認してからコミットする。

### 30分ごと: 進捗監査

- 直近30分でコミットが積まれたか。画面は良くなったか
- 同じ問題を繰り返し触っていないか（堂々巡りの検出）
- 詰まっていたら**原因を特定して打ち手を変える**

## 行き詰まったときの決まり

同じ問題に2回連続で当たったら、手を止めて**外を見る**。

- 競合・類似作の作り方（Natsu-Mon、Shin-chan、A Short Hike、Alba 等）
- 市場・レビューの声（何が評価され、何が飽きられているか）
- SNS・コミュニティでの言及（どの絵が刺さっているか）

調べた結果と、それを受けて何を変えたかを下のログに残す。

## 判断ログ

新しいものを上に足していく。社長が戻ったとき、ここを読めば経緯が分かる。

## 2026-09-02 イテレーション67 — 五時のチャイムを足したら、無音のファイルを作っていた

**足したもの**: **五時のチャイム**。17時に町のスピーカーから鐘が4音鳴り、
「五時の チャイムが 鳴った。」と出る。2000年の団地の夕方は、これが帰る合図だった。
夕方はヒグラシと甲虫が出る時間でもあるので、**遊びの合図としても働く**。
旋律は本物を使わず、下降する4音を鐘の倍音（1 : 2.76 : 5.40 : 8.93）で鳴らし、
低域だけ通して遠くから聞こえるようにした。

**ここから3つ、続けて掘り当てた**:

1. **音が鳴らない**。`[chime] 再生 playing=True` と出るのに、
   録った音の RMS が 1 サンプルも変わらない。ファイルを直接測ったら
   **peak = 0.0000 の完全な無音**だった。原因は合成側で、
   立ち上がり（25ms）の途中は `env` が 0 から始まるのに
   「`env` が小さくなったら打ち切る」と書いていたので、
   **1サンプル目で打ち切って何も書き込まれていなかった**
2. **`--import` が終わらない**。これを調べていて、`.godot/imported` が
   **7.4GB・29700ファイル**になっているのを見つけた。
   Godot が `screenshots/` 以下の**撮影したPNGを全部インポート**していた。
   `screenshots/.gdignore` を置いて解決（102ファイル・数秒で完了するようになった）。
   `.gitignore` に例外を書いて、この印だけは追跡する
3. **音量が足りない**。直したあとも -9dB ではセミの声に埋もれていた。-5dB に上げた

**確認（実測）**: 17時をまたぐ0.25秒ごとの RMS。

```
前(0〜3.0秒) -25.0dB → 直後(3.25〜5.0秒) -17.0dB   （8dB 上がる）
```

**この回の教訓**: 「鳴っている」と報告するプログラムを信じずに、
**出てきた音そのものを測った**から見つかった。
`playing=True` は「再生を開始した」としか言っていない。
