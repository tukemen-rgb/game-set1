# 自走モード（社長 不在時）

社長が海外で長期間承認できない間、承認を待たずに前へ進めるための取り決め。

## 前提: 何が詰まっていて、何が動かせるか

**画像パイプラインは社長本人が律速**（GPTが生成→社長がGitHubへアップ）。
不在の間これは進まない。したがって**自走で進めるのは画像に依存しない部分**に限る。

| 領域 | 不在中に進むか |
| --- | --- |
| ゲーム本体（遊び・演出・見た目の作り込み） | **進む** |
| 背景プレートの受け入れ機構（届いた時に使える状態にする） | **進む** |
| 生成画像そのもの | 止まる（社長の操作待ち） |
| 有料APIの導入 | 止まる（課金の判断が要る） |

## 回すループ

### 5分ごと: 批評 → 1件だけ直す

**辛口ユーザー（プレイヤー視点）**と**辛口クリエイター（作り手視点）**の
両方から現状を叩き、**その回で一番効く1件だけ**を直す。

- 辛口ユーザー: 面白いか。やることがあるか。手応えがあるか。飽きないか
- 辛口クリエイター: 作りとして甘くないか。嘘くさくないか。独自性はあるか。
  「ぼくのなつやすみの劣化コピー」で終わっていないか

毎回、**実際に動かした画面（キャプチャ）を根拠にする**。想像で批評しない。
直したら必ずビルド→シーン生成→キャプチャで確認してからコミットする。

### 30分ごと: 進捗監査

- 直近30分でコミットが積まれたか。画面は良くなったか
- 同じ問題を繰り返し触っていないか（堂々巡りの検出）
- 詰まっていたら**原因を特定して打ち手を変える**

## 行き詰まったときの決まり

同じ問題に2回連続で当たったら、手を止めて**外を見る**。

- 競合・類似作の作り方（Natsu-Mon、Shin-chan、A Short Hike、Alba 等）
- 市場・レビューの声（何が評価され、何が飽きられているか）
- SNS・コミュニティでの言及（どの絵が刺さっているか）

調べた結果と、それを受けて何を変えたかを下のログに残す。

## 判断ログ

新しいものを上に足していく。社長が戻ったとき、ここを読めば経緯が分かる。

## 2026-09-01 イテレーション2 — 「何も残らない」を潰す（コレクション性）

**批評（辛口ユーザー）**: 8月31日まであるのに、やることがセミ取りだけ。
捕まえても数字が1増えるだけで**何も残らない**。3日で飽きる。

**批評（辛口クリエイター）**: 時間帯で空の色は変わるのに、**やることが同じ**
なのが致命的。時間が「見た目の演出」でしかなく、遊びに接続していない。
これでは「ぼくのなつやすみ」の骨格だけ真似た抜け殻になる。

**打った手**: セミを1種類から**6種類**にし、**時間帯で顔ぶれが変わる**ようにした。
これで「時間の経過」が初めて遊びに接続する。

- ニイニイゼミ(朝) / クマゼミ(朝〜昼) / アブラゼミ・ミンミンゼミ(昼) /
  ツクツクボウシ(夕) / ヒグラシ(夕方だけ・捕獲率40%で最難関)
- 朝→昼→夕の切り替わりで顔ぶれを入れ替え、「セミの こえが かわった……」と通知
- **図鑑**（日をまたいで残る）を追加。HUDに `ずかん 2/6`、未捕獲の個体には
  近づくと「★みつけていない！」を表示して手を伸ばさせる
- 初捕獲時は「ずかんに はじめて のった！」の専用演出
- 日記と最終日のまとめにも図鑑の進捗を反映
- 種類ごとに体色と捕獲率を変え、難しい種ほど価値が出るようにした

**結果**: キャプチャで確認。HUDに「ずかん 0/6」、日記に「ずかんは あと 5しゅるい。」
が出ることを目視。**31日間プレイし続ける理由**が初めて成立した。

**次に効きそうな所**: 商店街のカメラで主人公が豆粒すぎる（望遠圧縮が
活きていない）。店に入れず何も起きないのも辛口クリエイターの指摘どおり。



## 2026-09-01 イテレーション1 — 1枚目の検証と方針転換

**批評（辛口クリエイター）**: 遠景が板を並べただけで嘘くさい。空が
プロシージャルの単色グラデで、実写の情報量に全く追いついていない。

**出来事**: GPT が生成した `BG-danchi-noon` が届いた。写真としては優秀だが、
**下絵を完全に無視してゼロから描かれていた**。カメラの高さも建物配置も
別物で、床に敷く背景プレートとしては使えない（3Dキャラと遠近が合わない）。

**打った手**: 捨てずに使い方を変えた。シーンを囲む**円筒パノラマ**として採用。
遠景なら画角の一致が要らないため、この用途なら問題なく使える。
UVは上72%だけを使い写真の地面部分は捨て、横に5回まわしてタイルしている。
公園カメラの見た目が明確に良くなったことをキャプチャで確認。

**途中で潰した不具合2件**:
- `ingest_images.sh`: アップロード名が既にIDと同じ場合、MAP.txt の改名が
  自己移動になり `mv` がエラーで全体が停止していた（実運用で発覚）
- 画像が Godot に未インポートだと `ResourceLoader.Exists` が false になり、
  パノラマが無言で消えていた。取り込み後の import を必須手順として確認

**次の一手**: GPT は下絵追従が苦手と判明したので、`docs/prompts/GPT_NOTES.md`
に方針転換を書いた。残り7枚の `BG-*` より、一致を要求しない
**遠景パノラマ・テクスチャ・汚し**を優先してもらう。
