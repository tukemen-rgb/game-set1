# Drained3600 床・天井・手すりの接続修正 — 2026-09-16

既存 `BalconyStructuralContactRepair` の継続修正です。最新の制作前提はユーザー指示の **1990年代・大阪の千里中央**。具体的な年は未確定です。旧資料の2000年設定は今回のUnity制作の年代根拠にしません。震災・復興テーマは追加しません。

元の Drained3600 の排水口・ホース・サッシ・室外機などを保持し、床2メッシュ、手すり、返し手すり、天井板、点検口だけを再構成しました。Grounded3600 の旧形状に差し替えていません。元ZIPと入力GLBは変更していません。

## 実際に直した箇所

| 箇所 | 修正前の実測・観察 | 今回の修正 |
|---|---|---|
| 床 | 排水口周囲を含む約1.226 m²が欠損 | 雨樋切り欠きの座標順序を訂正。排水穴を残して床を復元 |
| 排水口の周囲 | 半径49 mmの16点すべてに床面なし | 16点すべてを実際の上向き三角形で支持。中心には穴を保持 |
| 床下地と防水層 | 下地が4 mm膜のうち3.2 mmに重複 | 仕上がり高さを保ち、層の境界を一致 |
| 格子 | 上桟まで56.5 mmの空隙 | 上下の桟に接続。正面27本・返し5本を全LODで保持 |
| 柱脚 | 支柱とベースプレートに23.5 mmの空隙 | 支柱をプレートまで延長。EPDMとプレートの0.5 mmの隙間も解消 |
| 返し手すり | 長さ1.2 mで床の外側へ延伸 | 壁側へ向け、実際の床に合わせて0.970 mに調整。中間・端部の柱を勾配床上の座へ接地 |
| 天井点検口 | 元データは垂直。単に寝かせると天井板と干渉 | 水平配置し、天井板・下地に開口と補強材を設定 |
| 点検口の指掛け | 黒い箱が表面から突出 | 板の実開口、薄い縁、内壁、底を持つくぼみ形状に変更 |

床の原因は、`(x0,x1,z0,z1)` を `shapely.box(minx,miny,maxx,maxy)` に渡していたことです。正しい雨樋切り欠きは XZ の `[1.60,0.00,1.78,0.18]`。既存のauthoring JSONはこの順序でしたが、生成済みメッシュは一致していませんでした。従来の「閉じたメッシュ・正の体積」という検証だけではこの欠損を検出できません。

排水穴の設計半径は43.4 mmです。粗いLODでも中心から半径42.5 mmまで床が塞いでいないことを確認しています。ホース・排水口の頂点、面、変換、UVは元GLBと照合しています。排水の水理・施工性能を検証したものではありません。

## 再生成

Python 3.12で `UnityProject/Tools/requirements-balcony-repair.txt` の依存関係を使用します。入力は元の `balcony_drainage_integration_models_2026-09-16.zip` 内の `generated` フォルダです。

```bash
python -m pip install -r UnityProject/Tools/requirements-balcony-repair.txt
python UnityProject/Tools/build_balcony_structural_contact_repair.py \
  --input-root /absolute/path/to/original/generated \
  --output /absolute/path/to/new/output --render
```

出力先は新しいフォルダを指定します。旧CLIの `--drained-dir` は入力引数の別名です。`--guardrail-dir` と `--soffit-dir` は移行用に受け取りますが、部品は現在のversioned ownerソースから生成し、材質は元Drained GLBから取得する旨を実行時に明示します。

## 引き継げた実体と残件

添付TXT2件、軽量引き継ぎ、原本ZIP17/26個を読み込めました。全体ZIPの取得が途中でHTTP 502となったため、完全に取得できた内包ZIP16個のCRC・SHA256を元台帳と照合し、色付きモデルZIP1個を別途照合しています。残る9個はこの実行環境では未回収です。今回使った排水・手すり・天井の元ZIPはすべて照合済みです。詳細は同梱の `input_provenance.json` を参照してください。

Unity実行環境がここにはないため、compile/import/render、実際の3840×2160画像と100%クロップ、時間方向のちらつき・LOD遷移、実機負荷は未確認です。Visual Fidelityは未採点・未合格で、以前の実装準備度93を完成率にはしません。

既存のガラス表現、窓のUV／法線、表面の反復模様、経年表現、他部品の接合は今回の修正範囲外です。CPUプレビューは実際のガラスの透過・屈折・反射やGIを再現しません。寸法・材料・施工細部はモデリング上の仮定で、1990年代の特定製品を確認した事実ではありません。次はこの修正版を正式Unity ownerと照合し、実レンダーで外観を判断します。
