# 公園（丸い池）再現度 監査 — 参考画 vs 現状

- 参考画: `docs/reference/park_pond_gpt.png`（864×502、正午、GPT 生成）
- 現状: `screenshots/sweep/v_park_12.0/frame00000008.png`（正午 CamPark）、
  `screenshots/sweep/v_park_18.3/frame00000008.png`（夕方 CamPark）
- 数値は PIL で領域平均を取った RGB（0–255）。位置の話は CamPark
  `(17, 2.4, -21.5) → (-1, 1.2, -11)`, FOV 55（横約 85°）を前提にしている。
  右 = ワールド -z 側、左 = +z 側、正面 = -x 側。
- 生成元は `scenes/BuildSummer.cs`。**ソースは変更していない。**

構図（池の位置・大きさ・目線の高さ・団地の見える向き・手前左の大木）は
すでに合っている。違いはほぼ「色」と「物の作り」に集中している。
重要度順（画の印象を変える順）に並べる。

---

## 1. 芝の色 — 画面の半分を占め、いちばん印象を変える

- **参考画**: 暗いオリーブ緑。手前 (92,102,32)〜(109,116,43)、中景 (98,119,28)。
  踏まれて土が透けた茶色い斑があり、池のふちの外周は特に擦れている。
- **いま**: 黄緑のライム色。手前 (165,208,104)〜(174,217,104)、中景 (184,232,134)。
  参考画より明度が約 1.8 倍、彩度も高く、蛍光色に見える。
  まだら（`mottle`）はアルファ 0.22 で撮影画にほぼ写っていない。
- **直すなら**: `BuildGroundAndRoads` の
  `TexMat(BestTex("gen/TEX-grass_summer.jpg","grass"), new Vector2(43,43))`
  に tint を渡す。目安 `new Color(0.62f, 0.60f, 0.40f)`（現状 ×0.6 で参考画の
  値に寄る）。`BuildPark` の `mottle` は `AlbedoColor` を茶寄り
  `(0.36,0.30,0.12, 0.45)` に。加えて、ふちの外周 7.1〜8.2 m に土色の
  薄いトーラス（`(0.45,0.40,0.22, 0.35)`）を一枚寝かせると参考画の
  「踏み跡の輪」になる。

## 2. 池の水の色 — 「濁った緑の池」が「プールの水」になっている

- **参考画**: 濁ったオリーブ緑 (84,94,60)、奥 (77,85,55)。空はほとんど
  映らず、木と団地の暗い映り込みが縦に伸びている。波は緩い横波。
- **いま**: ターコイズ (121,164,158)、奥 (122,173,177)。アルベドは緑
  `(0.22,0.31,0.21)` なのに、`MetallicSpecular 0.45` + `Roughness 0.34` で
  空の水色が全面に乗って青くなっている。法線 `NormalScale 1.4` の細かい
  波が全面に均一に出て、参考画の緩い波と違う。
- **直すなら**: `BuildPark` の `waterMat`：`MetallicSpecular 0.45 → 0.12`、
  `Roughness 0.34 → 0.5`、`AlbedoColor → (0.20,0.26,0.14, 0.94)`、
  `NormalScale 1.4 → 0.8`、`Uv1Scale (3,3) → (2,2)`。水底の円盤
  `(0.2,0.24,0.18)` は `(0.10,0.12,0.08)` まで落とすと透けが暗くなる。
  映り込みは gl_compatibility では出ないので、対岸側（-x 側）に暗緑の
  半透明の帯を水面直上に置く手が現実的。
- **夕方**: 水が茶色 (119,83,62) の泥に見える。`scripts/SummerMain.cs`
  の `Colors.White.Lerp(sunColor, 0.8f)` の 0.8 を 0.4 程度に。

## 3. 池のふちの質感 — 玉石積みではなく「洗い出しコンクリート」

- **参考画**: 一体成形の低い環。表面は砂利の洗い出しで、粒は数 mm。
  色は暖かい灰茶 (110,98,73)、日陰側 (71,73,47)。目地や個々の石は見えない。
  断面は外側が丸い（現状のトーラス×0.7 と同じ）。
- **いま**: `gen/cobble.png` を `(44, 2.2)` で貼っているため、こぶし大の
  玉石とモルタル目地がはっきり見え、「石垣」に読める。色はピンク寄りの
  灰 (133,131,122) で参考画より明るく冷たい。
- **直すなら**: `BuildPark` の `rim` と内側の立ち上がり円柱の材質を
  `TexMat("photo/gravel_concrete.jpg", new Vector2(60f, 3f), new Color(0.62f,0.56f,0.45f), roughness: 1f)`
  へ（同じ写真を屋上に使っているので追加素材は不要）。cobble を残すなら
  `Uv1Scale (44,2.2) → (160, 8)` まで細かくして tint を `(0.58,0.52,0.42)` に。

## 4. 針葉樹 — 段数・色・本数が違う

- **参考画**: 池の右に大木 1 本（幹が右のふちのすぐ外）、すべり台の左に
  小さいもの 1 本。どちらも **2 段**（上に細長い円錐、下に広いスカート、
  間に幹が見える）で、葉は細かく密、色は暗緑 (31,42,14)。大木の高さは
  団地 3 階分（約 8〜9 m）。
- **いま**: **4 段**の太い円錐を積んだクリスマスツリー型。段の下面が
  平らに見える。色は tint `(0.42,0.6,0.4)` と青い環境光で青緑
  (39,67,60)。さらに `BuildTrees` の `DecoTrees` 列（`x=-27..-13.4, z=-11.5`
  の 5 本、全部 species 1）が CamPark の右中央に「針葉樹の群れ」として
  写り、参考画では空き地と白い建物がある場所を塞いでいる。
- **直すなら**: `MakeTree` species 1 の `tiers` を 2 段に：
  `{ (1.2f, 2.2f, 2.6f), (4.2f, 1.3f, 4.6f) }`（幹の見える隙間 0.4 m）、
  tint を `(0.30,0.42,0.22)` に。`BuildTrees` の団地南の並木 5 本は
  `z=-11.5 → z=-1`（棟の裏）へ移すか 2 本に減らす。大木の位置
  `spots[7]=(0,-20)` は参考画と一致しているので据え置き。

## 5. 団地の色味 — 青灰ではなく暖かい灰

- **参考画**: 壁 (92,94,88)、ベランダ帯 (95,93,86)。黄味の灰に黒い雨だれと
  苔の染み。妻面は無窓で、上端に明るいパラペットの縁取り。
- **いま**: 壁 (92,105,107)、ベランダ帯 (123,138,146)。同じ明るさだが青に
  寄っている。原因は `BuildEnvironment` の `AmbientLightColor (0.6,0.65,0.7)`
  と `FogLightColor (0.75,0.85,0.95)`（正午の `hor (0.65,0.82,0.95)` が
  そのまま霧色になる）。5 階・ベランダ連続・手すりの白・布団・妻面の雨どい・
  屋上パラペットは **OK**。
- **直すなら**: `BuildEnvironment` の `AmbientLightColor → (0.66,0.64,0.60)`。
  `SummerMain.cs` 側でも `ambient = hor.Lerp(White,0.45)*0.8` が青を持ち込む
  ので、`hor` ではなく `hor.Lerp(new Color(0.9,0.85,0.75), 0.5)` から作る。
  `DanchiBlock` の `Concrete (0.7,0.68,0.64)` 自体は暖色なので触らない。

## 6. 砂場 — 位置は合っているが、生垣に埋まって砂も見えない

- **参考画**: 左下、池の左に 1 半径ほど離れて、濃茶の角材で囲った
  明るいベージュの砂 (143,128,93)。
- **いま**: 位置 `(13,0,-8)` は画面上ほぼ同じ場所（左端 15%・高さ 62〜68%）
  で **OK**。しかし `BuildCommunityHouse((12,0,-4))` の前の生垣が
  `z=-8.4, x=9.6..15.3` に並び、砂場 `x=11.2..14.8, z=-9.8..-6.2` と
  重なって砂場の上に生垣が乗っている。中身は `"dirt"` テクスチャで
  暗い土。
- **直すなら**: 集会所を `(12,0,-1.5)` へ（生垣が `z≈-5.9` になり離れる）
  か、生垣を西面へ回す。砂の `TexBox(...,"dirt",...)` は
  `MeshI(BoxMesh, ..., Mat(new Color(0.86f,0.80f,0.64f)))` に。

## 7. 空と雲 — 入道雲の球が「白い玉」として写る

- **参考画**: 天頂は濃い青、地平線に中くらいの積雲が多数（空の 4 割）。
- **いま**: 空のグラデーションは近いが、`BuildBackdrop` の球の入道雲のうち
  `(-8,26,36)`（CamPark 正面から左 36°・仰角 21°）が左上に白い丸い塊として
  切れて写り、右上はパノラマ写真の巨大な雲一つが占める。参考画のような
  「小さな雲が散る」空ではない。
- **直すなら**: 写真パノラマがある時（`hasPlate`）は球の雲 4 つを作らない
  （`foreach (Vector3 pos in clouds)` を `if (!hasPlate)` で囲む）。
  空は `SkyTopColor (0.2,0.45,0.85) → (0.16,0.36,0.78)` で少し濃く。

## 8. 右の地平線 — 空き地と遠い木立が無く、写真の建物が見えている

- **参考画**: 大木の右は開けた草地。地平線に落葉樹の暗い木立の帯、
  その手前に細い土の道。建物は無い。
- **いま**: 右端にパノラマ写真の 3 階建て（`BG-danchi-noon.jpg` を
  `Uv1Scale x=5` で 5 回繰り返しているうちの 1 つ）が写り、芝とパノラマの
  境が硬い直線になっている。
- **直すなら**: `BuildBackdrop` に species 0（丸い木）の列を
  `z≈-45, x=-10..30`、`Scale 1.6` で 8 本ほど並べて境を隠す。
  パノラマの回転（`pano.RotationDegrees.Y`）を振って、CamPark の右
  （-z 方向）に写真の空・木立側が来るように合わせるのでもよい。

## 9. 白い 4 階建て — 参考画にあって、いまは無い

- **参考画**: 団地の右奥、大木の左に、白い外壁・縦長の窓・平らな屋上の
  4 階建て。針葉樹の群れではなくこれが右奥の壁になっている。
  画面 x=70%（正面から右へ約 21°）、距離は団地よりやや奥。
- **いま**: 同じ方向にあるのは #4 の DecoTrees の列。
- **直すなら**: `BuildBackdrop` か `BuildPark` に
  `MeshI(new BoxMesh{Size=(9,13,9)}, (-30,6.5,-14), TexMat("plaster",(3,4),(0.93,0.92,0.88)))`
  ＋ `"facade"` の窓帯を -z/+x 面に貼った箱を置く（`hasPlate` で間引かれる
  `x<-35` の遠景ブロックの代わり）。

## 10. すべり台 — 左右が逆で、色が濃い

- **参考画**: 右に水色の鋼管の「はしご＋囲い」があり、滑走面は
  **左（画面左、+z 側）へ**降りる。滑走面の上端両脇に赤い側板。
  鋼管は明るい水色、滑走面はステンレスの幅広い樋。
- **いま**: はしごが左、滑走面が右へ降りる（`BuildSlide` は -z へ降りる
  設計で、CamPark の右が -z）。青は `(0.2,0.45,0.8)` で紺寄り。はしごの
  支柱が細い線に見え、囲いが無い。位置 `(-6,0,-11)` は **OK**。
- **直すなら**: `BuildSlide` の `slide.RotationDegrees = new Vector3(0,180,0)`
  で反転。`blue → (0.25,0.55,0.85)`。踊り場の両側に
  `Box((0.06,0.3,0.8), (±0.45, top+0.15, -0.35), (0.8,0.3,0.15))` の赤い側板。
  はしごの支柱半径 `0.035 → 0.05`。

## 11. ブランコ — 参考画に無い

- **参考画**: すべり台の右にあるのは、すべり台自身の青い囲い。ブランコは無い。
- **いま**: `(-2,0,-17)` に灰青 `(0.35,0.55,0.65)` のブランコ（座板・鎖付き）
  が大木の左に写る。
- **直すなら**: `BuildPark` の `swing` を CamPark の外
  （例 `(-8,0,-4)`、団地寄り）へ移すか、色をすべり台の青に揃える。

## 12. 夕方（18.3）固有 — 夕焼け写真の陸地が右上に写る

- **参考画**は正午なので比較対象ではないが、夕方の絵として不自然な点：
  右上に `SKY-sunset.jpg` の暗い陸地（山の影のような塊）が出ている。
  `Uv1Scale y=0.82` では方位によって写真下端の陸が残る。
- **直すなら**: `BuildBackdrop` の `duskMat.Uv1Scale (3, 0.82) → (3, 0.7)`
  か、`dusk.Position.Y 39 → 42` で陸の帯を画角の上へ逃がす。

## 13. 光の向きと影 — 正午より午後の光が参考画に近い

- **参考画**: 太陽は左上・やや手前。大木の影が右へ長く落ち、ふちの内側の
  奥に影の帯がある。
- **いま（12.0）**: 太陽がほぼ真上で影が短く、ふちにも木にも影が付かない。
- **直すなら**: ソースを触らず `SHOT_HOUR=15.0` で撮り比べる。
  常に寄せるなら `SummerMain.cs` の `_sun.RotationDegrees` の
  `-10f - 60f*arc` の 60 を 50 に（正午の最高仰角 70°→60°）。

## 14. 街灯 — 位置 OK、ポールが細い

- **参考画**: 砂場と池の間、白い建物の前にコンクリート柱（径 0.25 m ほど）。
  上端に短い腕木と小さな灯具。
- **いま**: `BuildParkLamp((11,0,-8.8))` が同じ場所に立つ。**OK**。
  径 `0.07` が細く、鉄管に見える。
- **直すなら**: `BottomRadius 0.07 → 0.13`, `TopRadius 0.05 → 0.10`、色を
  `Concrete` に。

## 15. 園路 — OK

- **参考画**: 幅 1.2 m ほどのコンクリート小道が砂場の奥から団地へ斜めに
  伸びる。表面は汚れて緑がかる (93,94,49)。
- **いま**: `z=-7.4` 幅 1.5 m の帯が同じ位置に写る。**OK**。
  色が白すぎるなら `TexMat(..., tint (0.8,0.8,0.7))`。

## 16. 手前左の大木 — OK

- **参考画**: 左上から新緑の落葉樹の枝が被る。
- **いま**: `spots[6]=(15,-13)` の丸い木が同じ位置に被る。**OK**。
  葉は #4 と同じ理由で少し青い（tint 無し・環境光）。#5 の環境光修正で
  一緒に直る。

## 17. 池の形・大きさ・ふちの幅・目線 — OK

- 池の横幅は両方とも画面幅の約 70%、ふちの手前の幅は直径の 6〜7%、
  遠いふちの位置は画面高さの 52% / 56%、地平線 46% / 51%。**OK**。
  CamPark を 0.2 m 下げると参考画とほぼ一致するが、誤差の範囲。

## 18. 集会所（左の白い 2 階建て） — 形 OK、上階が隠れる

- **参考画**: 上階に白い手すりのベランダ、1 階前に白い塀と刈り込み。
- **いま**: `BuildCommunityHouse` の形は合っている。CamPark からは
  手前の大木と街灯で上階ベランダが隠れ、白い塀に当たる要素が無い。
  #6 で北へ寄せれば上階が見える。塀は `Box((7,1.8,0.15))` を生垣の
  手前に置くと参考画の「白い壁」になる。

## まとめ（上位 5 件）

1. 芝を暗いオリーブに（tint ×0.6）— 画面の半分が変わる
2. 水を濁った緑に（反射 0.45→0.12、粗さ 0.5、アルベドを暗く）
3. ふちを洗い出しコンクリートに（cobble → gravel_concrete、暖かい灰茶）
4. 針葉樹を 2 段・暗緑にし、右奥の群れを消す
5. 環境光を暖色にして団地の青灰を取る
